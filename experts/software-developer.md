# Expert knowledge: Software Developer

Source knowledge to distill into workflow subagents. Not an agent itself.

## Fundamentals that do not expire

- Data structures and algorithms (complexity, when to use each structure)
- System design: scalability, consistency, availability (CAP theorem)
- Design patterns and when NOT to use them (avoid over-engineering)
- SOLID, DRY, KISS principles, with judgment, not as dogma
- Networking: TCP/IP, HTTP/HTTPS, DNS, TLS

## AI and assisted development (critical in 2026)

- Prompt engineering for coding agents (Claude Code, Copilot, Cursor)
- How to review and validate AI-generated code (never trust blindly)
- RAG, embeddings, and when to use an LLM vs a traditional system
- Basic fine-tuning vs prompting vs tools (function calling, MCP)
- Model limitations: hallucinations, bias, context limits

## Architecture and distributed systems

- Microservices vs monoliths (real trade-offs, not fashion)
- Event-driven architecture, message queues (Kafka, RabbitMQ)
- Databases: SQL vs NoSQL, when to use each, sharding, replication
- Observability: logging, tracing, metrics (OpenTelemetry)
- Idempotency, resilience, circuit breakers, retries with backoff

## DevOps and delivery

- CI/CD, containers (Docker), orchestration (Kubernetes)
- Infrastructure as Code (Terraform, Pulumi)
- Security: OWASP Top 10, secrets management, least privilege
- Cloud (at least one in depth: AWS, GCP, or Azure)

## Technical soft skills

- Effective code review
- Clear documentation (READMEs, ADRs - Architecture Decision Records)
- Testing: unit, integration, e2e, TDD when it applies
- Systematic debugging, not trial and error

## Languages and paradigms

- At least one statically typed and one dynamic language, in depth
- Functional programming (concepts: immutability, pure functions)
- Concurrency and parallelism (async/await, actors, locks)
