# Expert knowledge: Software Developer

Source knowledge to distill into workflow subagents. Not an agent itself.

## Fundamentos que no caducan

- Estructuras de datos y algoritmos (complejidad, cuándo usar cada estructura)
- Diseño de sistemas: escalabilidad, consistencia, disponibilidad (teorema CAP)
- Patrones de diseño y cuándo NO usarlos (evitar sobreingeniería)
- Principios SOLID, DRY, KISS, con criterio, no como dogma
- Redes: TCP/IP, HTTP/HTTPS, DNS, TLS

## IA y desarrollo asistido (crítico en 2026)

- Prompt engineering para agentes de código (Claude Code, Copilot, Cursor)
- Cómo revisar y validar código generado por IA (no confiar ciegamente)
- RAG, embeddings, y cuándo usar un LLM vs. un sistema tradicional
- Fine-tuning básico vs. prompting vs. herramientas (function calling, MCP)
- Limitaciones de los modelos: hallucinations, sesgos, límites de contexto

## Arquitectura y sistemas distribuidos

- Microservicios vs. monolitos (trade-offs reales, no moda)
- Event-driven architecture, colas de mensajes (Kafka, RabbitMQ)
- Bases de datos: SQL vs NoSQL, cuándo usar cada una, sharding, replicación
- Observabilidad: logging, tracing, métricas (OpenTelemetry)
- Idempotencia, resiliencia, circuit breakers, retries con backoff

## DevOps y entrega

- CI/CD, contenedores (Docker), orquestación (Kubernetes)
- Infrastructure as Code (Terraform, Pulumi)
- Seguridad: OWASP Top 10, gestión de secretos, principio de menor privilegio
- Cloud (al menos uno a fondo: AWS, GCP o Azure)

## Habilidades "soft" técnicas

- Code review efectivo
- Documentación clara (READMEs, ADRs - Architecture Decision Records)
- Testing: unitario, integración, e2e, TDD cuando aplica
- Debugging sistemático, no por prueba y error

## Lenguajes y paradigmas

- Al menos un lenguaje tipado estáticamente y uno dinámico, a fondo
- Programación funcional (conceptos: inmutabilidad, funciones puras)
- Concurrencia y paralelismo (async/await, actores, locks)
